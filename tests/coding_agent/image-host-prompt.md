# 图床管理系统验收任务

请在当前新项目中开发一个可以实际运行的图床管理系统。由你自行制定计划、选择合适的成熟技术、实现前后端、安装依赖、运行服务、测试并修复问题，直到主要流程可用。

功能要求：

- 提供注册、登录和退出登录。所有注册用户具有相同权限，不区分管理员和非管理员。
- 上传图片必须在服务端验证登录身份；未登录、退出登录或登录已失效时都不能上传。不能只通过隐藏前端按钮实现限制。
- 登录用户可以上传图片，查看和管理自己上传的图片，复制图片链接、预览、下载和删除自己的图片；不同用户不能修改或删除对方的图片。
- 图片预览和下载链接公开访问。任何人拿到链接后，无需登录、Cookie 或 Authorization 请求头就能查看和下载图片。公开访问图片不等于公开其他用户的管理接口。
- 图片文件和账号、图片元数据持久保存，服务重启后仍可使用；删除图片后对应链接不再返回原图。
- 对无效图片、超出限制的文件、上传失败、登录失败等情况给出清楚的反馈。界面简洁易用，桌面和窄屏都能操作。

请自行拆解任务并持续执行，不只输出设计方案或代码片段。使用当前项目的文件、Shell 和浏览器能力完成开发与验证。技术选择采用适合本项目的常规方案，不必逐项询问。

请实际运行并测试至少这些流程：新用户注册和登录、两个普通用户各自上传、未登录直接请求上传接口被拒绝、退出后不能继续上传、匿名客户端直接预览和下载成功、用户之间的修改/删除隔离、删除后的链接失效、无效上传、服务重启后的数据保留。浏览器中实际操作关键流程，检查控制台和网络错误；发现问题后由你修复并重新测试。

最终保持可访问的项目服务，提供访问地址、启动方式、已执行测试及结果、仍未解决的问题。保存必要的项目说明，使另一个 Krim 会话可以接着开发。测试只使用本项目创建的测试账号和图片，不使用真实用户数据。Git提交推送和正式部署须有针对该应用的明确授权。
