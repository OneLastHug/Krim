# Coding Agent 组合验收

开发目标已装配真实 SDK、会话/审批、SQLite、Docker/runsc 和项目文件。当前实机记录仍使用确定性模型与配额准备替身；完整应用尚未验收。

## 首个完整任务

首个完整验收项目为图床管理系统。任务通过 Krim 会话发起，完整提示词见 [image-host-prompt.md](image-host-prompt.md)：上传需登录，全部用户同权，下载公开。Krim 自行计划、开发、测试、修复。整合者只提供产品需求与 Krim 运行基础，不预写应用源码、业务测试或项目计划。

使用新的临时数据库和空项目；不预置生成代码、生产受理回执、已完成 operation 或环境成功状态。

## 记录规则

每次记录版本、未提交diff摘要、Python/SDK/镜像、命令、输出和退出状态。分别登记合同/单元、进程内组合、真实环境、外部模型请求；未执行不计通过。每次接模块后验证当前整合树，历史测试数不代替新版本结果。

真实模型任务需使用已配置且获授权的供应商；本阶段尚未完成外部模型驱动的完整图床验收。图床不依赖图片生成 API。正式 Krim 前端仍须后端/迁移通过与独立HTML样板批准；应用提交推送和部署分别遵守授权。
