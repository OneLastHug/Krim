# 正式聊天 Shell 验收：LeetCode Hot 100

请在当前项目中独立完成下面三道 LeetCode Hot 100 题，使用 Python 3 和标准库，不安装依赖。你自行规划、编写源文件与自动测试、通过 Shell 运行，并根据实际结果修复。不要只在聊天里贴代码或给出解题思路。

1. [1. 两数之和](https://leetcode.cn/problems/two-sum/)：实现 `two_sum(nums, target)`，返回两个不同下标，使对应数之和等于 target。输入保证恰有一组解，返回下标顺序不限。考虑重复数字、负数、零及不能重复使用同一元素；目标时间复杂度 O(n)。
2. [20. 有效的括号](https://leetcode.cn/problems/valid-parentheses/)：实现 `is_valid(s)`，判断仅由 `()[]{}` 组成的字符串能否正确配对且顺序嵌套。考虑空串、单个括号、连续配对、嵌套、交叉和不匹配；目标时间复杂度 O(n)。
3. [56. 合并区间](https://leetcode.cn/problems/merge-intervals/)：实现 `merge(intervals)`，把闭区间的重叠项合并，输出按起点升序排列的互不重叠区间。端点相同视为重叠。考虑空输入、单区间、未排序输入、包含、相邻端点和互不重叠；目标时间复杂度 O(n log n)。

执行要求：

- 首先用 Shell 检查当前工作目录、Python 版本和项目文件，确认在项目目录内工作。
- 将三题实现在 `solutions.py`，测试写在 `test_solutions.py`，每题至少 8 个测试场景。使用标准库 `unittest`，不要把预期结果写成无论实现如何都通过的断言。
- 必须通过 Shell 真正运行 `python3 -m unittest -v`，确认命令退出码和实际测试输出。若执行器先返回进程引用，继续读取进程状态和输出，不把“已启动”当“已通过”。
- 若测试失败，自行修复并重跑；不要删除失败场景来掩盖问题。
- 保存简短 `README.md`，包括运行命令、每题算法和时空复杂度。所有文件只写入当前授权项目，不修改项目外路径，不访问网络，不执行 Git 提交或推送。
- 最后汇报实际创建的文件、运行命令、退出码、测试场景数与结果，并说明任何未完成项。只依据真实工具结果声称完成。
